# Use of AI tools in development

AI tools supported the research, writing, implementation, testing and presentation of this project.

The support included:

- Structuring requirements, architecture decisions and implementation plans.
- Assisted implementation of the backend, interface, import, assignment, allocation, closing opinion and invoices.
- Preparing tests and investigating failures.
- Organizing documentation.

Product decisions and their reasons are recorded in the [PRD](product/prd.md) and the [architecture decisions](decisions/). The code and the automated checks make it possible to trace how those decisions were implemented.

## Responsibility

The author is responsible for the material and for explaining the flow, the allocation policy, the data provenance, the algorithms and their limits. Passing automated tests does not, by itself, prove human understanding of every line.

## Not the same as AI in the product

Using generative tools during development does not mean they are part of the product. The closing opinion uses deterministic rules and robust statistics, with no call to a language model. Forecasting and clustering were deferred.
